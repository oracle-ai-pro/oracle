Контент и Авторские права

Убедитесь, что ваш или ваши прикрепленные файлы обладают вашими правами, и то что вы имеете право их использовать. Ни в коем случае не создавайте и не загружайте контент, который нарушает права других людей. Наш ИИ не сможет создавать контент, даже если он ваш, если вы упоминаете про оскорбления, вред и насилие.

Также при прикреплении файла вы должны соблюдать правила конфиденциальности Core Node 2.6 ME3.

Правила (бета, как у ИИ-платформ):
• ≤50 символов ≈ 0,5% · 50–150 ≈ 1% · длиннее — пропорционально
• Интернет-поиск: ~5% известное / ~10% неизвестное
• Код / игры / сложные генерации: 20–40%
• При 100% отправка блокируется до конца окна (3–24 ч; при «спам-разгоне» дольше)
• Вторая шкала — расход за текущую неделю
• Сбросить лимиты вручную нельзя

Side Core Node

Урезанный Core Node в боковой панели браузера (Chrome / Edge / Chromium). История чатов, быстрые ответы, API настраивается в основном Core Node. Удобно держать ИИ рядом с любой вкладкой.

Скачать Side Core Node
Как установить вручную
  1. Скачайте side-core-node.zip и распакуйте папку на диск.
  2. Откройте браузер → chrome://extensions (или edge://extensions).
  3. Включите «Режим разработчика» (справа сверху).
  4. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку.
  5. Закрепите иконку Side Core Node на панели. При необходимости откройте боковую панель (Side panel).

API-ключи и тема подтягиваются из основного Core Node на том же профиле браузера (localStorage / общий origin, если так настроено в сборке).
